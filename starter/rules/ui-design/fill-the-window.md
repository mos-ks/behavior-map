**Rule.** Never cap the width of a page, panel, table or list in pixels. Layouts fill the window and grow with it. Limit only the line length of running prose, never the container that holds it.

**Why.** A fixed width leaves half of a wide screen empty.

**Applies / does not apply.** Dialogs, menus, tooltips and form fields may have a fixed size.
